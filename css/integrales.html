Regla de la potencia directa
1
∫ x⁵ dx
Fórmula
∫xⁿ dx = xⁿ⁺¹ / (n+1) + C
Aplicar con n = 5
= x⁽⁵⁺¹⁾ / (5+1) + C
Resultado
= x⁶/6 + C
2
∫ dx / x²
Reescribir
1/x² = x⁻²
Aplicar con n = −2
∫ x⁻² dx = x⁻¹ / (−1) + C
Resultado
= −1/x + C
3
∫ ∛x dx
Reescribir
∛x = x^(1/3)
Aplicar con n = 1/3
∫ x^(1/3) dx = x^(1/3 + 1) / (1/3 + 1) + C
Simplificar exponente
= x^(4/3) / (4/3) + C
Resultado
= (3/4) x^(4/3) + C
4
∫ dx / ∛(x²)
Reescribir
∛(x²) = x^(2/3) → 1/x^(2/3) = x^(−2/3)
Aplicar con n = −2/3
∫ x^(−2/3) dx = x^(1/3) / (1/3) + C
Resultado
= 3∛x + C
5
∫ (2x² − 5x + 3) dx
Linealidad
2∫x² dx − 5∫x dx + 3∫dx
Integrar cada término
= 2·(x³/3) − 5·(x²/2) + 3x + C
Resultado
= (2/3)x³ − (5/2)x² + 3x + C
6
∫ (1 − x)√x dx
Expandir el producto
(1 − x)·x^(1/2) = x^(1/2) − x^(3/2)
Integrar cada término
∫x^(1/2) dx − ∫x^(3/2) dx
Aplicar regla de potencia
= x^(3/2)/(3/2) − x^(5/2)/(5/2) + C
Resultado
= (2/3)x^(3/2) − (2/5)x^(5/2) + C

Resultado
= 3x³ + 12x² + 16x + C
8
∫ (x³ + 5x² − 4) / x² dx

x³/x² + 5x²/x² − 4/x² = x + 5 − 4x⁻²

∫x dx + 5∫dx − 4∫x⁻² dx

= x²/2 + 5x − 4·(x⁻¹/−1) + C
Resultado
= x²/2 + 5x + 4/x + C

10

x^(1/2)/(1/2) + 2·x^(3/2)/(3/2) + x^(5/2)/(5/2) + C

18
∫ (x² + 2x) / (x + 1)² dx
Reescribir numerador
x² + 2x = (x+1)² − 1
Verificación
(x+1)² − 1 = x² + 2x + 1 − 1 = x² + 2x ✓
Dividir
[(x+1)² − 1] / (x+1)² = 1 − 1/(x+1)²
Separar e integrar
∫1 dx − ∫(x+1)⁻² dx
Sea u = x+1, du = dx
∫u⁻² du = −u⁻¹ + C = −1/(x+1) + C
Resultado
= x + 1/(x+1) + C

9x⁵/5 − 12x⁴/4 + 28x³/3 − 16x²/2 + 16x + C
Resultado
= (9/5)x⁵ − 3x⁴ + (28/3)x³ − 8x² + 16x + C
