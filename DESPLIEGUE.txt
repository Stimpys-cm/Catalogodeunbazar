 BAZAR EN LINEA — Guía de despliegue con MongoDB + Vercel
══════════════════════════════════════════════════════════════

PASO 1 — Instalar Node.js
─────────────────────────
1. Ve a https://nodejs.org
2. Descarga la versión LTS (botón verde grande)
3. Instala normalmente
4. Verifica abriendo una terminal (cmd en Windows):
   > node --version   (debe mostrar v18 o mayor)
   > npm --version


PASO 2 — Instalar Vercel CLI
─────────────────────────────
En la terminal escribe:
   > npm install -g vercel

LISTO ------


PASO 3 — Obtener tu URI de MongoDB Atlas
──────────────────────────────────────────
1. Entra a https://cloud.mongodb.com
2. En tu clúster → Connect → Drivers
3. Selecciona Node.js, versión 5.5 o superior
4. Copia el string que parece:
   mongodb+srv://usuario:contraseña@cluster.mongodb.net/

   ⚠️  Reemplaza <password> con tu contraseña real
   ⚠️  Agrega el nombre de la BD al final:
       mongodb+srv://usuario:pass@cluster.mongodb.net/bazar

5. En Atlas → Network Access → Add IP Address → Allow from anywhere
   (0.0.0.0/0) para que Vercel pueda conectarse.


PASO 4 — Armar la carpeta del proyecto
────────────────────────────────────────
Estructura final de tu carpeta bazar-en-linea/:

  bazar-en-linea/
  ├── api/
  │   ├── _db.js          ← archivo descargado
  │   ├── inventario.js   ← archivo descargado
  │   ├── config.js       ← archivo descargado
  │   └── auth.js         ← archivo descargado
  ├── js/
  │   ├── db.js           ← reemplaza tu archivo actual
  │   ├── admin.js        ← reemplaza tu archivo actual
  │   ├── tienda.js       ← reemplaza tu archivo actual
  │   └── login.js        ← reemplaza tu archivo actual
  ├── css/                ← sin cambios
  ├── tienda.html         ← sin cambios
  ├── admin.html          ← sin cambios
  ├── login.html          ← sin cambios
  ├── vercel.json         ← archivo descargado
  └── package.json        ← archivo descargado


PASO 5 — Subir a Vercel
─────────────────────────
1. Abre la terminal en la carpeta del proyecto:
   > cd ruta/a/bazar-en-linea

2. Inicia sesión en Vercel:
   > vercel login
   (abre el navegador, inicia sesión con GitHub/Google/email)

3. Despliega:
   > vercel
   - "Set up and deploy?" → Y
   - "Which scope?" → tu cuenta
   - "Link to existing project?" → N
   - "Project name?" → bazar-en-linea
   - "In which directory is your code?" → ./  (solo Enter)
   - "Want to override settings?" → N

4. Vercel te da una URL provisional como:
   https://bazar-en-linea-abc123.vercel.app


PASO 6 — Agregar la variable de entorno MONGODB_URI
──────────────────────────────────────────────────────
OPCIÓN A (recomendada — desde el dashboard):
1. Ve a https://vercel.com/dashboard
2. Abre tu proyecto → Settings → Environment Variables
3. Agrega:
   Name:  MONGODB_URI
   Value: mongodb+srv://usuario:pass@cluster.mongodb.net/bazar
4. Marca los 3 entornos: Production, Preview, Development
5. Guardar

OPCIÓN B (desde terminal):
   > vercel env add MONGODB_URI
   Pega tu URI cuando te lo pida

Después vuelve a desplegar para que tome efecto:
   > vercel --prod


PASO 7 — Verificar
────────────────────
Abre tu URL de Vercel.
- /tienda.html → debe cargar prendas (vacío al inicio, es normal)
- /login.html  → entra con admin / stiimpys2026
- /admin.html  → agrega una prenda de prueba
- Abre /tienda.html en otra pestaña → en ~8 segundos aparece

¡Listo! Tu bazar corre con MongoDB Atlas.

 COMANDOS ÚTILES
══════════════════════════════════════════════════════════════

   > vercel logs https://tu-url.vercel.app --follow
